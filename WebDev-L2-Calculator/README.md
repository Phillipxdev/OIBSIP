## Project Description

A fully functional browser-based calculator created as part of the Oasis Infobyte Web Development & Designing Internship.

The calculator performs basic arithmetic operations using a clean and responsive button-based interface.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Grid
- Responsive Web Design

## Features

- Addition, subtraction, multiplication and division
- Numeric and decimal input
- Clear calculator function
- Backspace/Delete functionality
- Division-by-zero error handling
- Operator chaining
- Dynamic calculator display
- CSS Grid button layout
- JavaScript event listeners
- Responsive user interface
