## Project Description

A responsive and interactive To-Do Web App created as part of the Oasis Infobyte Web Development & Designing Internship.

The application allows users to create and manage daily tasks by adding, editing, completing and deleting tasks.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- LocalStorage
- Responsive Web Design

## Features

- Add new tasks
- Pending tasks list
- Completed tasks list
- Mark tasks as complete
- Edit existing tasks
- Delete tasks
- Pending and completed task counters
- Task timestamps
- LocalStorage persistence
- Empty state messages
- Responsive design
