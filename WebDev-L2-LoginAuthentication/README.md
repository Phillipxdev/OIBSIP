## Project Description

A responsive client-side authentication system built as part of the Oasis Infobyte Web Development & Designing Internship.

The application allows users to register, log in, access a protected dashboard and securely log out. Passwords are hashed using SHA-256 before being stored.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Web Crypto API (SHA-256)
- Responsive Web Design

## Features

- User registration
- Login authentication
- Password validation
- Minimum 8-character password requirement
- Password must contain at least one number
- Duplicate username/email detection
- SHA-256 password hashing
- Protected dashboard
- Session checking
- Logout functionality
- Form validation
- Responsive design

## Project Structure

- `register.html` - User registration page
- `login.html` - User login page
- `dashboard.html` - Protected dashboard
- `style.css` - Application styling
- `script.js` - Authentication functionality

## Note

This project demonstrates client-side authentication for educational purposes. Production authentication should use a secure backend and server-side session management.
