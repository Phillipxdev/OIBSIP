## Project Description

A responsive temperature converter website created as part of the Oasis Infobyte Web Development & Designing Internship.

The application allows users to convert temperature values between Celsius, Fahrenheit and Kelvin with input validation and absolute zero checks.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design

## Features

- Celsius, Fahrenheit and Kelvin conversion
- Temperature unit selection
- Numeric input validation
- Absolute zero validation
- Clear conversion results
- Responsive layout
- Clean and user-friendly interface
